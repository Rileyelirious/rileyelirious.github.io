Creaject

GitHub Repository

A gamified project-based productivity app with a markdown editor, taskboards, flowcharts, and notes all built with version control systems in mind.

A great solution for project documentation since it works well with VCS, but Creaject is made for anyone who wants to make anything. I wanted a straightforward application that lets me do all of the project planning I could ever want in one place, so here it is.

Back-end built with C# and designed to be loosely coupled with the Godot front-end.

Personal ELO Bot

GitHub Repository

A self-hosted and easily customizable Discord bot that can handle ELO calculations using TrueSkill and provide matchmaking server-wide with other features geared towards competitive gaming in your community.

Particularly targeted towards community owners that want full control over their matchmaking bot, allowing theming specific to the game it is focused on matchmaking for. Every color and line of text the bot outputs is fully customizable using a simple JSON.

Technologies

  • Python
  • SQLite
  • Discord.py
  • Microsoft TrueSkill

MinecraftTogether

GitHub Repository

A suite of tools to create, manage, and tunnel/network your Minecraft servers with ease.

Designed specifically for the slightly-technical Minecraft player who wants to make a server easily but also does not have access to port-forwarding. Having tunnelers spawn in parallel to the server is a very nice alternative to port-forwarding.

Technologies

  • Python
  • JSON
  • Tkinter
